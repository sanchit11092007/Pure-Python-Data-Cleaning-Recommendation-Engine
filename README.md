# Pure Python Data Cleaning & Recommendation Engine

This project focuses on building a data cleaning pipeline and a simple recommendation engine using **pure Python**, without relying on high-level machine learning libraries.

The goal of the project is to strengthen understanding of data preprocessing, data quality issues, and basic recommendation logic from first principles.

---

## Problem Statement

In real-world applications, raw data is often incomplete, inconsistent, and noisy.  
Before any modeling or recommendation system can be built, the data must be carefully cleaned and structured.

This project addresses two core problems:
1. Cleaning and preparing raw data for analysis
2. Generating basic recommendations using rule-based and similarity-driven logic

---

## Dataset Overview

The project works with structured datasets containing user or item-related information.  
The raw data includes common real-world issues such as:
- Missing values
- Inconsistent formatting
- Duplicate or noisy records

The data is processed step by step to ensure reliability before recommendations are generated.

---

## Approach

The project follows a clear and structured workflow:

### 1. Data Cleaning
- Handling missing and invalid values
- Removing duplicates
- Standardizing data formats
- Validating input consistency

### 2. Data Preparation
- Transforming cleaned data into usable structures
- Creating mappings and relationships between entities
- Ensuring data integrity for downstream logic

### 3. Recommendation Logic
- Rule-based and similarity-oriented recommendations
- No external ML libraries used
- Emphasis on understanding logic rather than optimization

The entire pipeline is implemented using **pure Python** to reinforce foundational concepts.

---

## Key Features

- End-to-end data cleaning workflow  
- Reusable and modular Python functions  
- Clear separation between cleaning and recommendation logic  
- Focus on readability and maintainability  

---

## Tools & Technologies

- Python (standard libraries only)

No high-level machine learning frameworks were used in order to maintain full transparency of the logic.

---

## Learnings & Outcomes

Through this project, I gained hands-on experience in:
- Designing data cleaning pipelines from scratch  
- Understanding the impact of data quality on downstream systems  
- Implementing recommendation logic without black-box abstractions  
- Writing clean, modular, and readable Python code  

This project strengthened my foundation for more advanced machine learning–based recommendation systems.
